### Ожидаемые эндпоинты фронтенда

В исходниках фронтенда (в файле `api.ts`) указано, что запросы отправляются на базовый URL: `/api/...`

**Важно:** Сейчас во фронтенде включен режим заглушек. Чтобы фронтенд начал отправлять реальные запросы к вашему бэкенду, нужно в файле `hahaton/fsp-platform/src/services/api.ts` поменять флаг `USE_REAL_BACKEND` на `true`.

---

#### 1. Получение списка кандидатов
- **Метод**: `GET`
- **Путь**: `/api/candidates`
- **Что отправляет фронт**: Может отправлять Query-параметры для фильтрации (например: `?searchQuery=...&minSalary=...`).
- **Что ожидает в ответ**: Массив объектов `Candidate`.

#### 2. Отправка прямого оффера
- **Метод**: `POST`
- **Путь**: `/api/offers`
- **Что отправляет фронт**: Объект оффера:
  ```json
  {
    "candidateId": "string",
    "companyName": "string",
    "companyLogoUrl": "string",
    "positionTitle": "string",
    "salaryMin": 100000,
    "salaryMax": 200000,
    "employmentType": "Полная удаленка | Гибрид (Москва) | Офис (СПб) | Релокация",
    "message": "string",
    "perks": ["string"]
  }
  ```
- **Что ожидает в ответ**: Полный объект `JobOffer` (ваш сервер должен добавить поля `id`, `status: "pending"` и `sentAt`).

#### 3. Изменение статуса оффера (Принять / Отклонить)
- **Метод**: `PATCH`
- **Путь**: `/api/offers/{offerId}/status`
- **Что отправляет фронт**:
  ```json
  {
    "status": "accepted" // или "declined"
  }
  ```
- **Что ожидает в ответ**:
  ```json
  {
    "status": "accepted" // или "declined"
  }
  ```

#### 4. Смарт-подбор
- **Метод**: `POST`
- **Путь**: `/api/recruiter/smart-match`
- **Что отправляет фронт**:
  ```json
  {
    "teamName": "string",
    "description": "string",
    "targetCategory": "string",
    "requiredStack": ["string", "string"],
    "salaryMin": 100000,
    "salaryMax": 200000
  }
  ```
- **Что ожидает в ответ**: Объект со списком кандидатов, у которых добавлено поле `smartScore` (процент совпадения):
  ```json
  {
    "candidates": [
      {
        // ... все поля Candidate ...
        "smartScore": 95
      }
    ]
  }
  ```

#### 5. Симуляция запроса к реестру ФСП
- **Метод**: `POST`
- **Путь**: `/api/fsp/sync/{candidateId}`
- **Что отправляет фронт**: Пустое тело.
- **Что ожидает в ответ**:
  ```json
  {
    "success": true,
    "message": "строка с результатом проверки"
  }
  ```
