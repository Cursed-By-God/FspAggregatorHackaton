### Ожидаемые эндпоинты фронтенда (согласно руководству по API)

Фронтенд отправляет запросы на базовый URL: `/api/...`

**Важное требование из руководства:**
- CORS должен разрешать запросы с `http://localhost:5173`.
- При `GET /api/candidates` поле `contacts` в профилях должно возвращаться как `null` (скрыто).
- Когда рекрутер делает `PATCH /api/offers/{id}/status` и кандидат (система) отвечает `accepted`, контакты должны открываться.
- `POST /api/recruiter/smart-match` должен рассчитывать поле `smartScore` (0-100) и формировать текстовое объяснение `matchExplanation`.

---

#### 1. Получение списка кандидатов
- **Метод**: `GET`
- **Путь**: `/api/candidates`
- **Что отправляет фронт**: Query-параметры (фильтры поиска).
- **Что ожидает в ответ**: Массив объектов `Candidate`. Контакты (`contacts`) должны быть скрыты (null).

#### 2. Отправка прямого оффера
- **Метод**: `POST`
- **Путь**: `/api/offers`
- **Что отправляет фронт**:
  ```json
  {
    "candidateId": "string",
    "companyName": "string",
    "companyLogoUrl": "string",
    "positionTitle": "string",
    "salaryMin": 100000,
    "salaryMax": 200000,
    "employmentType": "string",
    "message": "string",
    "perks": ["string"]
  }
  ```
- **Что ожидает в ответ**: Сохраненный объект `JobOffer` (с `id`, `status: "pending"`, `sentAt`).

#### 3. Изменение статуса оффера (Принять / Отклонить)
- **Метод**: `PATCH`
- **Путь**: `/api/offers/{offerId}/status`
- **Что отправляет фронт**: `{ "status": "accepted" }`
- **Что ожидает в ответ**: Обновленный статус. При `accepted` фронт ожидает, что после этого он получит доступ к контактам кандидата.

#### 4. Смарт-подбор
- **Метод**: `POST`
- **Путь**: `/api/recruiter/smart-match`
- **Что отправляет фронт**:
  ```json
  {
    "teamName": "string",
    "description": "string",
    "targetCategory": "string",
    "requiredStack": ["string"],
    "salaryMin": 100000,
    "salaryMax": 200000
  }
  ```
- **Что ожидает в ответ**: Список кандидатов, дополненный полями `smartScore` и `matchExplanation`.

#### 5. Симуляция запроса к реестру ФСП
- **Метод**: `POST`
- **Путь**: `/api/fsp/sync/{candidateId}`
- **Что отправляет фронт**: Ничего.
- **Что ожидает в ответ**:
  ```json
  {
    "success": true,
    "message": "Успешно проверено"
  }
  ```

#### 6. Отправка результатов независимого тестирования (из документации)
- **Метод**: `POST`
- **Путь**: `/api/testing/submit`
- **Что отправляет фронт**:
  ```json
  {
    "testSessionId": "sess-test-9941",
    "candidateId": "fsp-cand-01",
    "answers": [
      { "questionId": "q-1", "selectedOption": "a" },
      { "questionId": "q-2", "selectedOption": "b" }
    ]
  }
  ```
- **Что ожидает в ответ**: 
  ```json
  {
    "testSessionId": "sess-test-9941",
    "score": 94,
    "isPassed": true,
    "assignedCategory": {
      "id": "cat-backend-senior",
      "specialization": "Бэкенд-разработка",
      "grade": "Senior"
    },
    "passedAt": "2026-10-05",
    "cooldownUntil": "2027-01-05",
    "message": "Тест успешно пройден"
  }
  ```
